# 🐍 Snake Game

A modern and responsive **Snake Game** built using **HTML, CSS, and JavaScript**. The game works smoothly on desktop, laptop, tablet, and mobile devices with responsive controls and an adaptive game board.

## 🚀 Features

* 🐍 Classic Snake gameplay
* 🎮 Arrow Keys and WASD controls
* 📱 Mobile touch controls
* 🏆 High score saved using Local Storage
* ⚡ Increasing game speed
* 💀 Game Over screen
* 🔄 Play Again option
* 📱 Fully responsive design
* 💻 Desktop and laptop optimized
* 🌙 Modern dark/glassmorphism UI
* 🚫 No external libraries required

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* HTML5 Canvas
* Local Storage

## 📂 Project Structure

snake-game/

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing! 🎮

## 🎮 Controls

| Action     | Control            |
| ---------- | ------------------ |
| Move Up    | ⬆️ / W             |
| Move Down  | ⬇️ / S             |
| Move Left  | ⬅️ / A             |
| Move Right | ➡️ / D             |
| Restart    | Enter / Play Again |

## 📱 Responsive Design

The game automatically adjusts to different screen sizes:

* 💻 Desktop
* 🖥️ Laptop
* 📱 Mobile
* 📲 Tablet
* 🔄 Landscape mode

## 🏆 Scoring

Eat the food to increase your score. Every few points, the snake becomes faster, making the game more challenging.

Your highest score is automatically stored in your browser using **Local Storage**.
